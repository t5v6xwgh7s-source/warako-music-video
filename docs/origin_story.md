- **事実として起きたこと**と、**順子ちゃんがそこに見いだした意味**を分けて書く(同じ段落に混ぜない)。
- 日付・出所(誰が・何で確認できるか)を付ける。確認できないことは「未確認」と書く。
- 公開する場合は、先に本人が内容を確認する(個人名・店名・金額・他人の発言は特に)。

## 2. 順子ちゃんがそこに見いだした意味

(本人の言葉で書く。解釈は解釈として、事実と分けて置く。)

- 軸になっている流れ: **遠回り → 虹 → 会いたい → 帰る → おかえり**
- 重なった言葉: 預言カフェの「遠回りに思えるプロセス」/ 曲の「遠回りした日々も抱きしめながら」/ 最後の「またねじゃなくて／おかえりって」/ 絵本『おかえり』
