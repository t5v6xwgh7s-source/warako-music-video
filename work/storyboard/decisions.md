# decisions (preview v3b: 歌詞なし・タイトルなし・虹と歌声の同期)

## 最上位方針
- **絵本を説明するMVを作らない。曲から絵本へ行きたくなるMVを作る。**(`CLAUDE.md` 上位ルール)
- 中心モチーフは「虹」: 離れた二つの場所をつなぐもの／まだ会えていない存在との距離／向こう側へ続く道。
  遠く → 会いたい → 近づく → 向こう側へ届く → 役目を終える → 帰る場所(親分)。
- 歌詞テロップ・タイトルは映像から削除(`--lyrics` / `--title` で再表示できる。コードは残してある)。
  `lyrics_timing.tsv` と歌詞ファイルは同期資料として残す。「おかえりって」も文字では出さず歌声に任せる。

## 歌唱位置(推定)と虹キュー
- 歌唱位置は `lyrics_timing.tsv` の推定。今回、音量解析での全面再推定はしていない。確度は中(1番〜2サビ)・低(雨上がり〜以降)。
- 虹キュー R1〜R7 は `rainbow_cues.md` に記録(歌唱開始・cut-in完了・余裕・歌唱中の画面を計算で検査、全キューOK)。
- 虹の歌詞とカットの対応:
  - R1「空にかかった虹が」18.8 → 遠い淡い虹(仮: p030左頁の上部、彩度を下げたクロップ)
  - R2「虹の向こうで会いたい」34.2 → 0.3秒の短いCUTで、歌い出しの0.35秒前に虹が完成。強い虹(拡大+彩度を少し上げる)。うさぎは見せない。続けて頁全体(遠くにうさぎの後ろ姿=存在の気配)
  - R3「虹の向こうで／もう一度」48.5 → 虹に沿って視線が進むパン
  - R4 2回目「虹の向こうで会いたい」76.1 → 近い虹とうさぎの後ろ姿(まだ会えない)
  - R5 2回目「虹の向こうで／もう一度」88.8 → 虹の光へ寄る(もう少しで届く)
  - R6「虹の向こうで会えたなら」147.5 → 虹を描かず、扉の向こう側へ光のブルーム(この遷移だけ通常と変えた)
  - R7「虹の向こうで／また」168.4/172.2 → 最後の遠い虹 → 虹色の光 → 暖かな光 → 宇宙酒場

## 既存素材の限界(正直な記録)
- 既存45枚で虹が描かれているのは **p030左頁の1枚だけ**。R1〜R5・R7はすべてその絵の切り出し。
  切り出しは頁の上部に限られ、段階の違いは「近さ・色・視線の動き」で出している。**R1〜R5が似て見える**のは素材不足のため。
- 新しい静止画は `work/generated/image_requests.md` の RAINBOW_01/02/03a,b,c/04 として依頼を記録(まだ生成していない)。
- 既存の絵に虹を合成していない。彩度の調整(R1は下げ、R2は上げ)だけを行っている。

- 「おかえりって」は虹なし・字幕なし・台詞なし。カメラは2%以内のゆっくりした寄りのみ。

## 切替方法
- 重要な「虹の向こうで会いたい」(R2/R4)は0.3秒の短いCUT(ディゾルブ)で、歌い出しの0.35〜0.55秒前に虹を完成させる。長いクロスフェードで曖昧にしない。
- その他は穏やかなディゾルブを維持。R6だけ暖かな光のブルーム(通常のディゾルブと違う遷移)。
