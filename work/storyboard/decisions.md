# decisions (preview v1)

## 前提と仮決定
- 素材: 音源 `song.m4a`(3:04.16 / Opus / 48kHz / stereo / 約86BPM)、絵本ダミー(HTML)から抽出した見開き画像45枚。
- **歌詞ファイル未提供**。音声認識も使えなかったため、RMSの谷(0:12 / 0:33.5 / 0:56 / 1:15.8 / 1:32 / 1:44.8 / 2:07 / 2:25 / 2:46)から区間を推定。歌詞照合は未実施。**区間名は仮**。
- **QR未提供**。エンドカード(2:52.5〜、11.7秒)にQRの置き場と自動配置ロジックだけ用意。`assets/qr/*.png` を置いて再ビルドすれば入る。QRなしのpreviewとして書き出した。
- 宇宙酒場: 専用画像がなかったので、絵本の最終見開き `p088_welcome`(星空・天の川・親分アップ)を「宇宙酒場の親分」として使用。

## 構成の考え方
- 絵本の順序を、曲の呼吸に合わせて間引いて使った(45枚中34枚)。説明字幕は入れていない。
- 記憶させる(雪・待つのをやめた・「昨日もいた。今日もいる」) →
  違和感を残す(2:07 置物の後ろの大きな影 / 声 / 灯り) →
  再登場(2:25 扉「おう。入んな。」→ 親分) → 気づく(2:40 「やっと気づいたか」)。
- 色の遷移: 冷たい青い雪(0:12〜) → 暖色の部屋・季節 → 夜の路地の灯り → 酒場の琥珀色 → 星空の宇宙酒場。
- 最大音量の最終サビ(2:25〜2:46)に「扉→親分→気づく」を集中。2:46の静けさ(スペクトル重心も低下)で空席→帰る場所→エンドカード。

## 静止 / 動かした理由
- 完全静止に近い: 雪(0:12)、「昨日もいた。今日もいる」(0:38.75)、虹の橋(1:38)、置物は代わりではない(2:01)、気づく瞬間(2:40)、空席(2:46)。感情が決まる場面は動かさない。
- 動かした: 見開きの横長を活かした左→右パン(足音・季節・路地)、Zoom inは「近づく/迫る」場面のみ(安心の春、影、声、扉)。
- 秒数は1カットあたり3〜10秒。サビ・ブリッジで短く、Aメロ・別れで長く止める。

## 文字
- 歌詞の常時字幕なし。曲名(2〜6秒)、親分の台詞3か所(入んな / やっと気づいたか・ずっとここにいたぞ / 帰ってきたか・まあ座んな)、最後に「おかえり」のみ。
- フォントはIPAゴシック(この環境で使えた日本語フォント)。明朝系や手書き風は未使用。

## 改善候補(次に一緒に決める: A静止でOK / B新規絵 / C AI動画 / D削除・構成変更)
- 歌詞を入れて区間と台詞の位置を実照合する。
- 2:07〜2:25のブリッジは5カットで急ぎ気味。「迷う→声」を絵ひとつ足すと呼吸が出る(B候補)。
- 最終サビ頭の扉が開く瞬間、親分が振り向く瞬間は動きが効く(C候補。`work/generated/video_requests.md` 参照)。
- 宇宙酒場への到着(星空へ切り替わる瞬間)に、酒場から星空へカメラが引く動画があると「到着地点」になる(C候補)。
- 絵本ダミー全体が同じ絵柄なので、画面の変化が少ない区間は光の粒子(ゆらぎ)を足す案もあり。
