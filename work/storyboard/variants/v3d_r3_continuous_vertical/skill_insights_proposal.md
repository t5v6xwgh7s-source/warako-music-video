# music-video-maker Skill への追記案(未適用 — 人間の確認後に反映)

## 横→縦(アスペクト変換)
1. **全情報の保存より、意味の保存。** 横絵を全部見せようとすると(fit+ぼかし拡張)、縦では主題が小さく弱くなる。左右を捨ててよいカットを先に決める。
2. カットを「人物・生き物(顔と視線を切らない)/風景・光・虹(大胆に捨てて満たす)/見開き・コラージュ(全体が意味ならfit)」に分類してから構図を決める。
3. 中央クロップは禁止。カットごとに cx/cy/zoom を指定し、空の領域へのパンは避ける(被写体のない場所を横切るパンは無意味)。
4. 距離感の物語(遠い→近づく→中に入る→越える)は、縦ではズーム量と画面占有率で作れる。R1〜R7を同じ構図にしない。
5. 原画が縦長(3:4など)なら、zoom 2〜4 の上部クロップで空・光を満たせる。素材不足と判断する前に fill を試す。
6. タイミング(カット表)は横から1行も変えない。`resolve_cuts` の出力を format 間で比較して一致を検査する。
7. QRは縦用に台紙サイズを再設計(安全余白)し、実レンダーのフレームからデコード確認。
8. 作業: 代表フレームの contact sheet で比較 → 局所修正 → フルレンダー(11分)。A/B は別名で残す。
